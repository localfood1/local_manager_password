# Локальный менеджер паролей

Небольшое локальное приложение на Python. Перед первым запуском установите
библиотеку шифрования:

```powershell
python -m pip install cryptography
```

Запуск:

```powershell
python .\password_vault.py
```

При первом запуске задайте мастер-пароль. После входа можно добавлять, менять,
удалять и копировать записи. Есть поиск, генератор паролей, URL для открытия
сайта, смена мастер-пароля и автоблокировка через 5 минут бездействия. Логин и
пароль в буфере обмена очищаются автоматически через 25 секунд, если буфер не
был изменён другой программой.

Данные лежат рядом с программой в папке `password_vault_data`.

## Важно

Записи хранятся в зашифрованном виде. Ключ выводится из мастер-пароля через
`scrypt`, а содержимое защищено шифрованием Fernet. При первом входе после
обновления прежнее текстовое хранилище будет автоматически зашифровано.

Мастер-пароль невозможно восстановить. Шифрование также не защищает от
вредоносной программы на уже разблокированном компьютере или от человека,
который знает ваш мастер-пароль.
