# 🔐 Локальный менеджер паролей

**Локальный менеджер паролей на Python с шифрованием данных.**

Простое приложение для безопасного хранения логинов, паролей и другой информации. Все данные хранятся локально на компьютере и защищаются мастер-паролем.

---

## ✨ Возможности

- 🔐 Шифрование хранилища
- 🔑 Мастер-пароль
- ➕ Добавление записей
- ✏️ Изменение записей
- 🗑️ Удаление записей
- 🔎 Поиск по сохранённым данным
- 🎲 Генератор надёжных паролей
- 🌐 Сохранение URL и открытие сайта
- 📋 Копирование логина и пароля
- 🔄 Смена мастер-пароля
- 🔒 Автоматическая блокировка через **5 минут бездействия**
- 🧹 Автоматическая очистка логина и пароля из буфера обмена через **25 секунд**
- 💾 Локальное хранение данных без облачной синхронизации

---

## 🛠️ Используемые технологии

- **Python 3**
- **Tkinter** — графический интерфейс
- **cryptography** — шифрование данных
- **Fernet** — симметричное шифрование
- **scrypt** — получение ключа из мастер-пароля

## 📦 Установка

Склонируйте репозиторий:

```powershell
git clone https://github.com/USERNAME/REPOSITORY.git
```

Перейдите в папку проекта:

```powershell
cd REPOSITORY
```

Установите необходимую библиотеку:

```powershell
python -m pip install cryptography
```

---

## 🚀 Запуск

Запустите приложение:

```powershell
python .\password_vault.py
```

При первом запуске приложение предложит создать **мастер-пароль**.

После входа можно создавать и управлять сохранёнными записями.

---

## 🔐 Хранение и защита данных

Данные приложения хранятся локально в папке:

```text
password_vault_data
```

Пароли и другие записи не хранятся в открытом виде.

Ключ шифрования получается из мастер-пароля с использованием:

```text
scrypt
```

Сами данные защищаются с помощью:

```text
Fernet
```

При первом входе после обновления приложения ранее использовавшееся текстовое хранилище автоматически преобразуется в зашифрованное.

---

## ⚠️ Важно

**Мастер-пароль невозможно восстановить.**

Если мастер-пароль будет утерян, доступ к зашифрованным данным может быть невозможен.

Также шифрование не защищает данные от:

- вредоносного программного обеспечения на уже разблокированном компьютере;
- человека, получившего доступ к разблокированному приложению;
- человека, которому известен мастер-пароль.

Поэтому используйте уникальный и достаточно сложный мастер-пароль.

---

## 📋 Буфер обмена

При копировании логина или пароля приложение автоматически очищает соответствующие данные из буфера обмена примерно через **25 секунд**.

Очистка выполняется только в том случае, если буфер обмена за это время не был изменён другой программой.
